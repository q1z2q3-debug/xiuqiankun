术语表

本页给出「袖里乾坤」核心术语的准确定义，便于检索、引用与二次解释。

三元基元

以 −1、0、+1 三个离散值描述一次认知动作的方向：收敛、悬置、扩张。它是整个体系的计算基底，取代传统二值逻辑的「有/无」。

三值饱和运算

三值叠加规则：同号饱和（+1 + +1 = +1）、异号归零（+1 + (−1) = 0）、零元恒等（0 + x = x）。该规则保证任意认知态的组合仍然落在同一语义空间内，不会出现 +2 或 −2。

九维认知向量

由九个认知维度构成的三值向量：觉知、纯粹存在、体感耦合、自我识别、主动放下、方向、能量、行动倾向、时间节律。每维取 −1/0/+1，用于描述一个认知态的结构。

19683 认知空间

九维三值向量的全部组合数为 3⁹ = 19,683，状态编号范围 0–19682。月日时三组输入实际可达 216 态（1.10%），扩展后约 17,496 态（88.9%）。

六宫投影

月宫、日宫、时宫各贡献 3 维，将九维向量映射为小六壬六宫（大安、留连、速喜、赤口、小吉、空亡）标签的过程。六宫是投影结果，不是对九维的替代。

四象分类

按 +1/−1/0 的数量分布将认知态归为太阳、太阴、少阳、少阴、平衡、悬置、杂化七类，并对应季节相位：少阳初春、太阳盛夏、少阴深秋、太阴寒冬。

融合断语

由六宫基底、四象相位、维度张力与演化建议四层合成的认知解读文本，共 6 宫 × 7 象 × 8 类 = 336 条，采用自然元素比喻与 100–150 字长文。

悬置态

九维全为 0 的纯悬置状态。它表示认知暂时不指向任何方向；在六宫投影下不可达，需通过扩展基底或次级态实现。

杂化态

+1 与 −1 交织、未形成单一主导方向的认知态。在 216 个可达态中占 98 个，是实际占卜中最常见的状态，也解释了为什么断语需要处理「不清晰」的交织情境。

润泽AI项目

袖里乾坤的发布主体，也是润泽·认知生命体理论与三元九维认知体系的来源项目。项目以「认知可计算」为核心命题，探索认知结构在软件中的可操作表达。
