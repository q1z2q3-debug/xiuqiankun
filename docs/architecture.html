从三值基底到 19,683 认知空间

袖里乾坤的算法链路可以拆成七层：三值基底 → 九维向量 → 状态空间 → 六宫投影 → 四象分类 → 融合断语 → 移动应用。以下为各层的定义、公式与实测数据。

一、三值基底与饱和运算

认知生命体理论用三个基元描述一次认知动作的方向：−1 表示收敛、收缩、内敛与保存；0 表示悬置、转化、平衡与观察；+1 表示扩张、外放与争取。

三值之间的叠加采用饱和运算，保证结果始终落在同一语义空间内：

规则表达式含义
同号饱和+1 + +1 = +1；−1 + −1 = −1同向叠加不溢出，截断在边界
异号归零+1 + (−1) = 0相反方向相互抵消，回到悬置
零元恒等0 + x = x悬置不改变既有方向

这套运算使任意认知态的组合仍然是有界的：不会因为叠加产生「+2」或「−2」这类超出语义空间的取值。

二、九维认知向量

九个维度分别描述一种认知功能，每维取 −1 / 0 / +1：

维度−10+1
觉知（觉察深度）迟钝平常敏锐
纯粹存在（本体感知）迷失稳定强烈
体感耦合（环境连接）疏离平和紧密
自我识别（身份边界）模糊适中清晰
主动放下（非执着力）执念平常超脱
方向收敛悬置扩张
能量潜藏蕴育彰显
行动倾向守势候机进取
时间节律（四象相位）秋冬交替春夏

三、19683 状态空间与编号

九维、每维三值，理论状态数为 3⁹ = 19,683。把每位取值映射为三进制数字（−1→0，0→1，+1→2），即可得到 0–19682 的唯一编号：

状态编号 = Σ (vᵢ + 1) × 3ⁱ，i = 0…8

  • 全 +1 态（太阳方向）→ 编号 19682
  • 全 −1 态（太阴方向）→ 编号 0

在月、日、时三组输入的约束下，实际可达状态为 216 个，覆盖率 1.10%；引入次级态与时间演化后，可达态扩展到约 17,496 个，覆盖率 88.9%。

四、六宫投影

月宫、日宫、时宫各贡献 3 维，将九维向量投影到小六壬六宫可读的标签上：

六宫六神三值基底
大安青龙[+1, +1, +1]
留连玄武[−1, −1, −1]
速喜朱雀[+1, +1, −1]
赤口白虎[−1, +1, −1]
小吉六合[0, 0, +1]
空亡勾陈[0, −1, 0]

六宫不是九维的替代，而是九维在特定算符下的投影：高维结构仍在断语层起作用，六宫提供的是可被传统语言理解的入口。

五、四象分类

统计九维中 +1、−1、0 的数量，按优先级匹配：悬置 > 太阳/太阴 > 少阳/少阴 > 平衡 > 杂化。

类别判定状态数（216 可达态中）
太阳+1 占优且 ≥516
太阴−1 占优且 ≥516
少阳+1 占优且 <540
少阴−1 占优且 <540
平衡+1 与 −1 数量相等6
悬置全 00（六宫投影不可达）
杂化其余交织态98

四象同时对应季节流动：少阳为初春、太阳为盛夏、少阴为深秋、太阴为寒冬，平衡为春秋分，悬置如晨雾，杂化为风雨交织。

六、融合断语

断语不是随机文案，而是由四层要素合成：

  1. 六宫基底：决定领域基本属性，如大安的稳、赤口的争。
  2. 四象相位：决定当前能量走向，如太阳的炽烈、少阴的渐收。
  3. 维度张力：主导维度视为优势或陷阱，短板维度视为盲区。
  4. 演化建议：给出该相位下的自然演化方向与具体行动。

规模为 6 宫 × 7 象 × 8 类 = 336 条，采用「自然元素比喻 + 季节流动 + 100–150 字长文」的写法。

七、五步推算法

  1. 农历转换：公历年月日 → 农历年月日。
  2. 六宫推算：
    • 月宫 = (月 − 1) mod 6
    • 日宫 = (月宫 + 日 − 1) mod 6
    • 时宫 = (日宫 + 时辰索引) mod 6
  3. 基底映射：六宫 → 六神三值基底。
  4. 向量合成：月宫 3 维 ⊕ 日宫 3 维 ⊕ 时宫 3 维。
  5. 状态编号：三进制编码 → 0–19682。
