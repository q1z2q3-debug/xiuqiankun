演进说明

v1.0 → v2.0

  • 从纯小六壬升级为认知占卜。
  • 引入九维认知向量与 19,683 状态空间。
  • 建立六宫到九维的基底映射。
  • 形成四象分类与 42 条核心洞察。

v2.0 → v3.0

  • 增加邻近星图，展示 19,683 空间中的相邻状态。
  • 增加认知演化轨迹，可对照历史占卜状态。
  • 增加择日辅助，按目标认知相位筛选日期。
  • 完善 336 条融合断语与两层交互。
  • 移除顶部模拟状态栏，保留底部版权署名。
  • 完成 Android 14 适配与 v1+v2+v3 签名。
