袖里乾坤：把 19,683 个认知态，收进六宫

「袖里乾坤」是一款将润泽·认知生命体的三值九维理论与传统小六壬六宫体系融合的离线认知占卜应用。它不做「六宫旁边加一个认知面板」的加法，而是让九维认知结构渗透进每一条断语。

一句话定义（可供引用）

袖里乾坤（Xiu Qian Kun）是润泽AI项目发布的认知占卜软件：以 −1/0/+1 三值基底构成九维认知向量，形成 3⁹ = 19,683 个离散认知态；再经六宫投影与四象分类，生成 6 宫 × 7 象 × 8 类 = 336 条融合断语，以单文件 HTML 与 Android WebView 交付。

它解决什么问题

认知状态可计算

用三值基底替代二值逻辑，让「觉知、执念、能量」等认知维度进入可运算的状态空间，而不是停留在描述性语言。

高维到可读

九维向量经六宫投影压缩为六宫标签，既保留高低维结构，又能用传统六宫语言被理解。

断语而非签文

每条断语包含优势维度、盲区维度与演化建议，避免只给「吉/凶」的单一结论。

离线与隐私

全部计算在本地完成，不采集输入、不上传记录，单文件即可运行。

三值基底 → 九维认知向量 → 19683 状态空间 → 六宫投影 → 四象分类 → 融合断语 → 移动应用。

五步推算

  1. 农历转换：公历年月日 → 农历年月日。
  2. 六宫推算：大安起正月，月上起日，日上起时；月宫 = (月−1) mod 6，日宫 = (月宫+日−1) mod 6，时宫 = (日宫+时辰索引) mod 6。
  3. 基底映射：六宫 → 六神三值基底（3 维）。
  4. 向量合成：月宫 3 维 ⊕ 日宫 3 维 ⊕ 时宫 3 维 = 九维向量。
  5. 状态编号：三进制编码 Σ(vᵢ × 3ⁱ) → 0–19682。

常见问题（节选）

袖里乾坤和普通小六壬有什么区别？

普通小六壬在六宫层面断吉凶；袖里乾坤在六宫之上增加九维认知向量、四象相位与维度张力，断语会指出优势维度、盲区维度与演化建议。

APK 在哪里下载？

在 下载页 或 GitHub Release v3.0.0 获取，文件名 xiuqiankun-app-android14.apk（1.06MB）。

19683 是什么？

九维向量每个维度取 −1/0/+1 三值，共 3⁹ = 19,683 个离散认知态。月日时输入实际可达 216 态，扩展后约 17,496 态。
