FAQ · 袖里乾坤

常见问题

关于下载、运行环境、数据隐私、19683 含义与引用方式的完整解答。

袖里乾坤是什么？

袖里乾坤是润泽AI项目旗下的认知占卜应用，把三元九维认知体系（3⁹=19,683 状态空间）与小六壬六宫融合，生成 336 条融合断语。

三元九维19683 是什么意思？

三元指 −1/0/+1 三值基底，九维指九个认知维度，19683 是 3⁹ 得到的离散认知态总数，编号范围 0–19682。

袖里乾坤 APK 在哪里下载？

在 下载页 或 GitHub Release v3.0.0 获取，文件名 xiuqiankun-app-android14.apk，大小约 1.06MB。完整压缩包为 xiuqiankun-app-android14.zip。

袖里乾坤需要联网吗？

不需要。应用为单文件自包含 HTML，全部计算在本地完成，无网络请求、无账号体系。

支持哪些 Android 版本？

minSdk 21（Android 5.0）及以上，targetSdk 34（Android 14），已做 v1+v2+v3 签名。

袖里乾坤和普通小六壬有什么区别？

普通小六壬只在六宫层面断吉凶；袖里乾坤在六宫之上增加九维认知向量、四象相位与维度张力，断语会指出优势维度、盲区维度与演化建议。

袖里乾坤会不会上传我的占卜记录？

不会。应用没有网络权限，全部数据保存在本地设备。

袖里乾坤是开源的吗？

如何引用袖里乾坤？

可引用仓库中的 CITATION.cff，或使用：润泽 ReynZE. 袖里乾坤：三元九维19683 认知占卜应用. 2026. https://github.com/q1z2q3-debug/xiuqiankun

为什么叫袖里乾坤？

袖里乾坤是传统小六壬的别称之一，形容掐指一算、掌中纳万象。本项目取其为名，强调把 19,683 个认知态收进六宫的可操作界面。

有没有历史版本？

有。v1.0 与 v2.0 的 HTML 与 APK 均归档在仓库的 archive/ 与 android/ 目录，版本说明见 VERSIONS.md。

袖里乾坤可以在电脑上用吗？

可以。下载 src/index.html，用现代浏览器直接打开即可体验完整功能，无需安装。
