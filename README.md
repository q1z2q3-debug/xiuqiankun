## 项目介绍

「袖里乾坤」是一款将**认知科学与传统术数融合**的移动应用。它不做简单的「六宫旁边加一个认知面板」，而是让**九维认知结构渗透进六宫每一条断语**，实现大认知空间（19,683 态）对小认知空间（六宫）的赋能。

### 核心创新

1. **三值基底**：用 −1 / 0 / +1 三元基元替代二值逻辑，对应「收敛 / 悬置 / 扩张」三种认知操作，并以三值饱和运算保证状态空间有界。
2. **九维认知向量**：觉知、纯粹存在、体感耦合、自我识别、主动放下、方向、能量、行动倾向、时间节律，共 9 个维度。
3. **19683 状态空间**：9 维三值向量构成 3⁹ = 19,683 个离散认知态，编号 0–19682。
4. **六宫投影**：月、日、时三宫各贡献 3 维，把高维认知态投影为小六壬六宫可读的标签。
5. **四象分类**：太阳 / 太阴 / 少阳 / 少阴 / 平衡 / 悬置 / 杂化，对应季节流动与能量相位。
6. **336 条融合断语**：六宫基底 × 四象相位 × 维度张力 × 演化建议，形成可读的长文洞察。

## 核心算法（五步）

1. **农历转换**：公历年月日 → 农历年月日
2. **六宫推算**：大安起正月 → 月上起日 → 日上起时
   - 月宫 = (月 − 1) mod 6
   - 日宫 = (月宫 + 日 − 1) mod 6
   - 时宫 = (日宫 + 时辰索引) mod 6
3. **基底映射**：六宫 → 六神三值基底（3 维向量）
4. **向量合成**：月宫 3 维 ⊕ 日宫 3 维 ⊕ 时宫 3 维 = 九维向量
5. **状态编号**：三进制编码 Σ(vᵢ × 3ⁱ) → 0–19682
