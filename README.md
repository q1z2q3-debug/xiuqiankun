# 袖里乾坤 (Xiu Qian Kun)

**认知生命体 × 小六壬 × 19683 认知空间 —— 融合占卜 APP**

---

## 项目概述

「袖里乾坤」是一款将「润泽·认知生命体」理论与传统小六壬占卜深度融合的移动应用。项目核心创新在于：

- **三值基底**：采用 −1 / 0 / +1 三元认知基元，替代传统二值逻辑
- **九维认知向量**：构建 9 维认知空间（觉知、纯粹存在、体感耦合、自我识别、主动放下、方向、能量、行动倾向、时间节律）
- **19683 状态空间**：3⁹ = 19,683 个离散认知态的理论空间
- **六宫投影**：将高维认知态投影到小六壬六宫（大安、留连、速喜、赤口、小吉、空亡）
- **336 条融合断语**：6 宫 × 7 象 × 8 类 = 336 条认知占卜断语

**核心哲学**：不是「六宫旁边加个认知面板」的加法，而是「九维认知结构渗透进六宫每一条断语」的深度融合。

## 核心算法

### 五步推算流程

1. **农历转换**：公历年月日 → 农历年月日
2. **六宫推算**：大安起正月 → 月上起日 → 日上起时
3. **基底映射**：六宫 → 六神三值基底（3 维向量）
4. **向量合成**：月宫 3 维 ⊕ 日宫 3 维 ⊕ 时宫 3 维 = 九维向量
5. **状态编号**：三进制编码 Σ(vᵢ × 3ⁱ) → 0~19682

### 四象分类规则

| 类别 | 条件 | 占比（4320 种输入） |
|------|------|---------------------|
| 太阳 | +1 数量 > −1 数量，+1 ≥ 5 | 0.37% |
| 太阴 | −1 数量 > +1 数量，−1 ≥ 5 | 0.37% |
| 少阳 | +1 数量 > −1 数量，+1 < 5 | 0.93% |
| 少阴 | −1 数量 > +1 数量，−1 < 5 | 0.93% |
| 平衡 | +1 数量 = −1 数量 | 0.14% |
| 悬置 | 全 0（纯 0 态） | 0%（六宫投影不可达） |
| 杂化 | 其他 | 2.27% |

1. 下载 `android/xiuqiankun-app-android14.apk`
2. 允许「未知来源」安装
3. 打开应用，选择农历月、日、时辰

直接用浏览器打开 `src/index.html` 即可体验完整功能。

## 断语风格

融合断语采用三层结构：
- **自然元素比喻**：觉知 = 风之眼、纯粹存在 = 根之深、体感耦合 = 水之流...
- **季节流动隐喻**：少阳 = 初春、太阳 = 盛夏、少阴 = 深秋、太阴 = 寒冬
- **长文洞察**：每类 100–150 字，涵盖认知状态、优势/陷阱、演化建议
